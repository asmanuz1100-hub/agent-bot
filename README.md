# Ички савдо-агент боти · ТЕСТ

Telegram орқали агент сменаси, жонли GPS, мижоз/дўкон, Грунтовка 7/1 (1/3/5 кг), товар ҳаракати, USD қарз/тўлов, касса ва акт сверка. Python 3.11+, Telegram Bot API. PostgreSQL учун `psycopg` (`requirements.txt`) талаб қилинади. Ҳозир Render web service + PostgreSQL’да webhook орқали ишлаяпти. Бу ишлаб чиқаришга тайёр SLA’ли маҳсулот эмас; тест ҳисоблари билан бошланг.

## Жойлаштириш ва муҳит ўзгарувчилари

- `BOT_TOKEN` — BotFather токени; ҳеч қачон GitHub/чатга ошкор қилманг.
- `ADMIN_IDS` — асосий админларнинг вергул билан ажратилган Telegram ID рақамлари. Иккинчи даражали админлар бот менюси орқали қўшилади, лекин бошқа админ қўша олмайди.
- `DATABASE_URL` — Render Postgres internal URL; `DB_SCHEMA=agentbot`. Ишчи Render хизматида маълумотлар **PostgreSQL**да сақланади. `DB_PATH` фақат маҳаллий SQLite синовига қолади; Render’нинг ephemeral дискини доимий база сифатида ишлатманг.
- `WEBHOOK_BASE_URL` (ёки Render томонидан бериладиган `RENDER_EXTERNAL_URL`), ихтиёрий `WEBHOOK_SECRET`.
- `OPENAI_API_KEY` — расмдан OCR учун ихтиёрий; калитсиз ҳам бот ишлайди. `OCR_MODEL` стандарт `gpt-4.1-mini`.
- `TEST_AGENT_IDS` — фақат тестда автомат қўшиладиган агент IDлари. Эски аккаунти алмаштирилган (disabled) ходим қайта фаоллаштирилмайди.

```bash
pip install -r requirements.txt
python -m unittest discover -v
python bot.py
```

`render.yaml` ва `.github/workflows/` файллари жойлаштириш/тест учун мўлжалланган. GitHub’га `.env`, база URL’и, токенлар ёки мижоз маълумотларини юкламанг. Маҳаллий SQLite режимида HTTP сервер битта оқимли; Render/PostgreSQL режимида кўп оқимли сервер ҳар сўров учун алоҳида DB уланишидан фойдаланади. Бир агент операциялари PostgreSQL user-row lock билан сериализация қилинади. Бир нечта Render инстансни ёқишдан олдин яна нагрузка ва транзакция тестлари ўтказинг.

## Агент учун қисқа йўриқнома

1. `▶️ Ишни бошлаш` → Telegram 📎 → «Локация» → «Жонли локацияни улашиш»ни **ўзингиз** танланг. Бот агент телефони GPS’ини автомат ишга тушира олмайди. Смена давомида админ GPS маршрутини кузатиши мумкин.
2. `🏪 Мижоз қўшиш`: дўкон локацияси → исм → дўкон номи → телефон → манзил → фото → изоҳ → тўлов санаси → товар/миқдор → тасдиқлаш. OCR ихтиёрий; таклифларни текширинг.
3. **`🗺 Мижозлар харитаси`**: агент аввал товар берган **ўзига бириктирилган барча дўконларни** харитада кўради. Дўкон нуқтасини босинг → «📍 Навигаторда очиш» билан йўлга чиқинг ёки «💰 Пул олиш»/«↩️ Товар қайтариш»ни босинг. Охирги икки тугма Telegram ботида айнан шу мижоз танланган ҳолда тегишли формани очади. Амал **агентнинг фаол сменаси ва янгиланиб турган жонли GPS** билан, миқдор/сумма киритиб, алоҳида тасдиқлагандан кейингина ҳисобга ёзилади. Харита ҳаволаси 15 дақиқа амал қилади: муддати тугаса ботдан янги ҳавола олинг. Мижозга ўтиш ҳаволаси 8 соатгача амал қилади, бошқа агент ундан фойдалана олмайди. Ҳаволаларни бошқаларга юборманг. Мижознинг локацияси киритилмаган бўлса, унинг маълумоти умумий ҳисобда қолади, аммо харита нуқтаси кўрсатилмайди.

4. `📦 Товар бериш`: мижоз → товар → дона/блок → миқдор → тасдиқлаш. **Топширилган пайтда** каталог нархи бўйича мижозда USD қарз пайдо бўлади. **Блок миқдори:** 1 кг = 10 дона, 3 кг = 6 дона, 5 кг = 2 дона. 
**Бир мижозга бир нечта қадоқ:** биринчи товарни тасдиқлагандан кейин «➕ Яна маҳсулот қўшиш»ни босинг; шу мижоз сақланади ва навбатдаги 3 кг ёки 5 кг товарни алоҳида киритасиз. Ҳар бир топшириш ўз USD қарзи билан қайд этилади. «👥 Мижозлар»да аввал мижозни рўйхатдан танланг, сўнг карточкасидаги товар/қарз/манзил/телефон ва фотосини кўринг. «✏️ Мижоз маълумотини ўзгартириш» орқали исм, дўкон номи, телефон, манзил, изоҳ, тўлов санаси, фото ёки дўкон локациясини янгилаш мумкин. Товар ва қарз тарихи таҳрирланмайди; профилдаги ўзгаришлар алоҳида журналга ёзилади.

5. `💵 Сотилган товар`: сотилган миқдор ва унинг асл топшириш партияси нархида USD қиймати қайд этилади; қарзни яна бир марта оширмайди. `↩️ Товар қайтариш`: мижоз қолдиғи/қарзини камайтиради; янги USD қайтаришлар асл топшириш партияси нархи бўйича тақсимланади.
6. `💰 Пул олиш`: мижоздан ҳақиқатан олинган USD суммани киритинг; у қарзни камайтиради. `🏦 Кассага топшириш`: кассир `/accept ID` ёки `/reject ID` билан текширади.
7. `⏹ Ишни тугатиш`: бот координаталарни қабул қилишни тўхтатади ва бир кунлик фаолиятни умумлаштиради. **Telegram ичида жонли локация улашишни ҳам ўзингиз тўхтатинг.** Кунлик ҳисоботда GPS координаталар кўрсатилмайди; админ алоҳида маршрут харитасида кўради.

Эски сўм операциялари USD балансга қўшилмайди. Аввал топширилган, лекин USD нархи сақланмаган айрим товарлар бир марталик миграцияда **жорий каталог нархи** билан ҳисобланган: тарихий нархлардан фарқ қилиши мумкин — админ текширсин. Партияга боғлаш функцияси қўшилишидан олдинги қайтаришлар бўлса, улар алоҳида бухгалтерия текширувини талаб қилади.

## Админ ва кассир

- Админ: «👥 Агентлар бошқаруви» → «➕ Агент қўшиш» орқали янги Telegram ID ва исмни киритади; агент /start юбориб киради. Асосий админ «🗑 Агент ҳисобини ёпиш»дан фойдаланиб, аввал сменани тугатган агентнинг фақат киришини ёпиши мумкин. Мижозлар, товар қолдиғи, қарз, касса, GPS ва операциялар тарихи ўчирилмайди, ўзгариш журналда сақланади. Бошқа админлар агент қўша олади, лекин ҳисоб ёпиш ҳуқуқига эга эмас. Админлар агент исмини ва хизмат рухсатларини ўзгартиради, товар/USD нархлар, маршрут, 1 кунлик/1 ҳафталик/1 ойлик умумий таҳлил, мижозлар, умумий (барча давр) акт сверка ва қисқа кунлик ҳисоботни кўради. «Умумий ҳисоб» алоҳида менюдан олиб ташланган.
- `🔐 Админ қўшиш` ва `🔁 Агент аккаунтини алмаштириш` — фақат `ADMIN_IDS`даги асосий админ. Аккаунт алмаштиришдан аввал эски агент **сменани тугатсин**. Янги Telegram ID аввал рўйхатдан ўтмаган бўлиши шарт. Эски ID ёпилади, мижоз/қолдиқ/ҳисоб тарихи янги ID’га боғланади; `role_audit`да из қолади. Янги агент `/start` босади.
- Кассир фақат кутаётган пул топширишларни кўради ва қабул/рад этади.
- `/failed` — админ учун кутилмаган хато берган Telegram update’лар журнали: Telegram ID, update ID, хатолик тури, уриниш сони ва статус. Уч марта хатолик берган update навбатни тўсмаслик учун ўтказиб юборилади, **лекин операция автомат қайта ўтказилмайди**; админ қарз/товар/касса журналларини текшириб, зарур тузатишни қўлда киритиши керак.

## Ҳисоботлар

«🗺 Умумий таҳлил»дан 1 кун, жорий календар ҳафтаси (душанбадан) ёки жорий календар ойини танланг. Кунлик харитада GPS маршрут бор; ҳафталик ва ойлик харитада **фақат шу даврда биринчи марта қўшилган мижозлар** локацияси кўринади. Ҳар бир агентнинг жами иш вақти, тахминий масофаси, янги мижозлари, **берилган товарнинг жами USD қиймати** ва **олинган пулнинг жами USD суммаси** алоҳида чиқади. Сотилган товар қиймати — бошқа кўрсаткич; тарихий суммасиз сотувлар USD сотув қийматига қўшилмайди. Ҳисоби ёпилган агентнинг шу даврдаги операциялари умумий ҳисоботдан чиқариб ташланмайди. Эски версиядаги суммасиз «сотилди» ёзувлари USD савдо жамига қўшилмайди, алоҳида огоҳлантирилади.

«📄 Акт сверка»да фақат мижоз танланади — сана киритиш шарт эмас, барча сақланган операциялар бўйича умумий акт шаклланади. Зарур бўлганда Python ҳисобот функциясида аниқ сана диапазони ҳам қўллаб-қувватланади.

## Харита ва махфийлик

Маршрут фақат агент ихтиёрий Telegram live-location улашганида ва сменаси очиқ бўлган вақтда қайд этилади. 5 дақиқадан катта узилиш ва паст GPS аниқлик масофани тахминий қилади. Харита фони ташқи харита плиткаларига ва интернетга боғлиқ; GPS маълумотлари ва мижоз карточкалари серверда алоҳида сақланади. Админнинг интерактив харита ҳаволаси имзоланган, **15 дақиқа** амал қилади ва бошқа одамга юборилмаслиги керак. Компания ходимларни GPS мониторинги ҳақида очиқ хабардор қилсин. Хабар беришни яширманг.

## Синов ва чекловлар

`python -m unittest discover -v` автомат тестлар. Реал Telegram live-location, OCR, Render restart, бир вақтда бир нечта агент, касса ва нарх партиялари бўйича **қўлда синов** ҳам зарур. Ҳақиқий тўловлардан олдин PostgreSQL backup ва тиклашни текширинг. PDF ҳисоботни бот тўғридан-тўғри яратмайди: акт сверка HTML файлини браузерда Print → Save as PDF қилиш мумкин. Offline GPS, 1C синхронлаш ва банк тўловлари автомат интеграцияси йўқ. GPS маълумотларининг сақлаш/ўчириш муддати ва муҳаррирлик/сторно аудит сиёсати ишлаб чиқилиши керак.
